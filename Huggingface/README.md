# RDS Live M3U Generator

Generates M3U playlists for RDS Live streams.

## Features
- Scrapes RDS Live website for stream URLs
- Generates downloadable M3U playlists
- Simple web interface

## Deployment
Deployed on Hugging Face Spaces: [Live Demo](https://huggingface.co/spaces/YOUR_USERNAME/rds-live-m3u-generator)

## Usage
1. Click "Generate M3U Playlist"
2. View playlist content
3. Download the M3U file
